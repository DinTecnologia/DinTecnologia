Há mais de 18 anos eu transformo problema de negócio em software rodando em produção — do banco
de dados à tela, passando pelo deploy. Sou parte da solução, não do problema. 🚀

### 🛠️ O que eu faço

- **Back-end:** APIs e serviços em **C# / .NET**, com SQL Server e PostgreSQL, acesso a dados
  enxuto (Dapper) e mensageria (RabbitMQ).
- **Front-end:** aplicações em **React / Next.js**, com TypeScript e Tailwind.
- **Cloud e entrega:** Docker, Kubernetes, Azure e AWS, com CI/CD no Azure DevOps e no GitHub Actions.
- **Produção de verdade:** observabilidade com Datadog, deploy blue-green e migração de banco sem
  tirar o sistema do ar.
- **IA aplicada:** agentes com Claude, OpenAI e Gemini — tool-calling, servidores MCP e automação
  de rotinas que antes eram manuais.

### 🔭 Agora

- Construindo uma plataforma SaaS em que pessoas de negócio criam agentes de IA agendados, sem programar.
- Estudando arquitetura de agentes: execução, custo, segurança e governança em escala.
